# python-calculator
my first project, built while learning python

## What it does
 - Arithmetic, powers and roots, and removes the extra '.0' for whole numbers
 - 1 Input for each calculations, it can only do 1 or 2 problems in one input
 - loops to make the user calculate till they type "quit"
 - round numbers correctly to fix how computers store floats

to run it you got to enter an equation containing 2 numbers and 1 sign, 1 sign and 1 number or 3 numbers and 2 signs. 

for example, if you want to calculate 4 * 2 + 2, just type it as an input, but it can't do order of operations
it always starts with the first problem then the second.

for roots, you would type sqr then the number, for example sqr 4 would give an output of = 2 

typing something that isn't a number crashes it for now, but I will fix it later
